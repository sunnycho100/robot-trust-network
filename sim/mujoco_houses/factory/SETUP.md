# Factory environment setup

Run from `sim/mujoco_houses`. The factory does not require the separate
`coohoi_mujoco` project. Existing commands using that project's virtual
environment remain valid; a fresh checkout can use its own environment:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-factory.txt
./scripts/fetch_assets
```

Validated with Python 3.13.7 and MuJoCo 3.17.0. On macOS, install ffmpeg with
`brew install ffmpeg`; on Linux use your distribution's ffmpeg package.
The existing asset fetch script initializes the pinned G1 model/config/published
locomotion policy. New trained checkpoints are not included in this change.

Keep roqsim as an adjacent checkout at `sim/roqsim_factory_upstream`. If it is
not already present, run:

```sh
git clone --filter=blob:none https://github.com/cps-test-lab/roqsim.git ../roqsim_factory_upstream
git -C ../roqsim_factory_upstream checkout 6e6999be07e56ebf442b2f20225f33b97c3a9f70
```

The complete checkout preserves the model-specific licenses and attribution.
No roqsim Python installation, ROS, Isaac or external Spot policy is required.
See [asset policy](ASSET_POLICY.md).

Headless physical validation:

```sh
PYTHONPATH=src .venv/bin/python -m unitree_demo.flexible_factory.plant_view \
  --duration 75 --report outputs/factory_check.json
PYTHONPATH=src .venv/bin/python -m pytest \
  tests/test_flexible_factory.py tests/test_factory_scene_labels.py -q
```

On macOS, record from a graphical terminal with `mjpython`:

```sh
PYTHONPATH=src .venv/bin/mjpython -m unitree_demo.flexible_factory.plant_view \
  --duration 50 --view hero --video outputs/factory_fast_cooperation.mp4
```

On Linux use `.venv/bin/python` with a working OpenGL/EGL context. `--view
cooperative_arms` shows the shared-panel task; `--view quadrupeds` shows Spot
walking. Recording shows tqdm progress. Videos, reports, upstream checkouts
and machine-specific experimental exports are not committed. Original factory
signage textures are included and may be regenerated by the scene builder.
